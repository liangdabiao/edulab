01

直觉模型：面积怎么算，结果都一样

面积是"可加的"：把图形切开再拼回去，面积不变。证明的秘密全在这一句。

伽菲尔德把两个全等直角三角形拼成梯形后，这块梯形的面积就有了两种算法： 直接套梯形公式，得 ½(a+b)²；或者把里面三块三角形的面积加起来，得 ½ab + ½ab + ½c²。 因为是同一块梯形，两个答案必须相等。等式一到手，剩下的只是化简。

下面这张「面积账本」就是把这个等式摆上桌：左边一栏是梯形面积，右边一栏是三块之和， 两栏永远等长。拖动上面的 a、b，无论怎么变，两条永远相等——勾股定理就是从这里"长"出来的。

面积账本：两条算法，永远等长

同一块梯形，两种算法。两栏等长 ⇔ 等式成立 ⇔ a² + b² = c²。

黄色 = 左边直角三角形 ½ab · 红 = 右边直角三角形 ½ab · 蓝灰 = 中间等腰直角三角形 ½c²。三者并排正好等于梯形。

02

正式证明：六步，全程只用面积

从「拼梯形」到「a²+b²=c²」，一行一行看，每一步都没有跳过面积。

设直角三角形的两直角边为 a、b（斜边 c）。把两个全等三角形拼成梯形： 两条直角边 a、b 分别作梯形的上下底，拼合处高为 a+b。这个梯形中间自然出现一个 等腰直角三角形，两条腰都是 c。下面用两种算法求同一块面积。

① 梯形S = ½(上底+下底)·高 = ½(a+b)(a+b) = ½(a+b)² ② 三块S = ½ab + ½ab + ½c² = ab + ½c² ③ 相等½(a+b)² = ab + ½c²　（同一块梯形） ④ ×2(a+b)² = 2ab + c² ⑤ 展开a² + 2ab + b² = 2ab + c² ⑥ 消项a² + b² = c²　∎
梯形高a + b两个三角形拼合处正好是两直角边之和

03

这个证明的边界

它优雅，但不是万能的。认清它证明了什么、没证明什么。

边界 1

只对直角三角形

勾股定理仅在有一个直角时成立。锐角/钝角三角形对应的是余弦定理 c² = a² + b² − 2ab·cos C，其中 C 是夹边夹角。

边界 2

不证明逆定理

面积等式推出「直角 ⇒ a²+b²=c²」。反过来「三边满足 a²+b²=c² ⇒ 有直角」是逆定理，需要另证——这里没有覆盖。

边界 3

依赖"面积可加"

本证明建立在「整体面积 = 各部分之和」与面积公式之上。对初学者是直观公理；严格化需先定义面积（如皮亚诺–约当测度）。

边界 4

不是总统首创定理

勾股定理比伽菲尔德早两千年。周髀算经（约公元前 1 世纪）已有类似拼图证明，而「总统证明」本质是古老的切拼法家族的一员。
