01

直觉模型：电子在搬家

燃烧、生锈、漂白、电池放电，都是同一件事——电子从一种原子搬到另一种原子。

丢掉电子的原子，化合价升高，叫"被氧化"；捡到电子的原子，化合价降低，叫"被还原"。 两个动作永远同时发生——有借必有还，氧化还原就是电子的一次"过手"。这也是反应命名的由来： 早期的"氧化"特指与氧结合，后来化学家意识到真正发生的是电子转移。

化学家没法一个个数电子，就用化合价（氧化数）记账。把它想成原子随身带着的 "电子账本"：反应前后价态升了，说明它把电子交出去了；降了，说明它把电子收进来了。 电子不会凭空消失，所以升高的总数必须等于降低的总数——这就是配平的唯一判据， 也是化合价升降法的全部依据。

下面四个反应依次展示了单变价、多变价、作酸参与、归中这几种常见情形： 先在演示模式里看完五步，再切到配平模式亲手试。

02

正式定义：化合价升降法五步

把"电子守恒"落成一套可执行的配平流程，教科书与竞赛通用的标准方法。

  1. 标变价——标出变价元素在反应前后的化合价，先找出谁升谁降。
  2. 列变化——算出每个变价物种"一个分子/原子"升或降多少。
  3. 求最小公倍数——让升降总量相等的最小整数，就是电子转移总数。
  4. 配系数——用最小公倍数除以各升降值得到初步系数，先配氧化剂与还原剂，再用观察法补齐其余物种。
  5. 查守恒——逐一检查每个原子左右相等，并确认总升 = 总降。

三个注意点：① 系数要化成最简整数比；② 同一元素既作氧化剂又作还原剂（如反应三中的 HCl）时， 只有"被氧化/被还原"的那部分计入升降，其余按观察法补齐；③ 生成物为偶数个原子（如 Cl₂）时， 若初步系数出现小数，整体同乘一个整数。

03

这个方法简化了什么

化合价是记账工具，不是分子里真实的电荷。

边界 1

只适用于氧化还原反应

复分解、酸碱中和这类无电子转移的反应，所有元素化合价都不变，升降法无从谈起 （升降都是 0，套不上公式）。先判断是否氧化还原，再决定用哪种配平法。

边界 2

化合价 ≠ 真实电荷

离子化合物里化合价接近真实电荷；共价分子（如 CO₂ 中碳 +4、H₂S 中硫 -2）里的氧化数是 按电负性"形式分配"出来的记账值，不代表原子真带着这么多电荷。

边界 3

配平数量，不说明机理

升降法只保证原子个数与电子数量守恒，并不描述电子从哪个轨道来、经过什么中间物种。 机理需要反应动力学与中间体证据，那是另一套学问。

边界 4

复杂反应要换方法

有机物常需先算碳的"平均氧化数"，会掩盖不同碳原子价态的差异；多步或离子体系反应， 更常用的反而是半反应（离子-电子）法。
