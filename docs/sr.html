01

直觉模型：同一束光，变长的路

先别管公式。光速对所有观察者都是 c——这是整个理论的锚。

想象一只"光钟"：上下两面镜子，一束光在中间来回反弹，每弹一次算走一步。如果这只钟静止， 光走的是笔直的上下直线；如果这只钟随飞船向右飞行，在静止的你看来，光还得追着镜子斜着走—— 于是每次往返的路径都更长。可光速是固定的：路径变长，一"步"就变慢。运动的光钟，因此走得慢。

上面实验区就是这个画面：A 钟静止，光子走直线；B 钟随飞船运动，光子走锯齿形的斜线。 拖动 β 越大，锯齿越平、路径越长，B 钟比 A 钟慢得越多。这个效应不是"钟坏了"——任何用 微观振动计时的钟（原子钟、放射性衰变、生命代谢）都会一起变慢，因为慢的根源是时间本身。

下面的世界线图讲同一个故事的另一面——双生子佯谬：一对双胞胎，哥哥坐飞船去 4 光年外的恒星再回来。 他掉头时经历了加速，所以两人不再是完全对称的观察者；结果不是悖论，而是精确的预言： 留在家的弟弟更老。拖动速度滑杆，看两兄弟年龄差怎么拉开。

02

正式定义：两条公设与 γ

整个理论只从两条公设出发，剩下的都是推论。

1905 年，26 岁的爱因斯坦在《论动体的电动力学》中提出两条公设： （1）物理定律在所有惯性参考系中形式相同； （2）真空中光速对所有惯性观察者都恒为 c，与光源运动无关。 从这两条出发，伽利略的"时间普适"不再成立：时间与空间必须通过洛伦兹因子 γ 一起变换。

公设 1物理定律在所有惯性系中形式相同（相对性原理） 公设 2真空光速恒为 c ≈ 2.998×10⁸ m/s，与光源运动无关 因子γ = 1 / √(1 − β²)，其中 β = v / c 推论Δt = γ·Δt₀（时间膨胀）　·　L = L₀ / γ（长度收缩，沿运动方向） 速度叠加u = (u′ + v) / (1 + u′v / c²)　（0.9c 加 0.9c 仍是 0.994c，不是 1.8c） 能量E = γmc²　·　静能 E₀ = mc²

03

这个模型简化了什么

狭义相对论只管匀速直线运动的惯性系，页面里还有几处刻意的省略。

简化 1

不含引力

页面只讲匀速直线运动的惯性系。引力会让时空弯曲，那是广义相对论的地盘；GPS 校时里那"快约 45 μs/天"就是引力项的贡献。

简化 2

瞬时掉头

双生子演示假设在恒星处瞬时掉头（无穷大加速度）。真实飞船必须经历减速—加速过程，正是这段非惯性运动让两兄弟不再对称，也是"佯谬"的答案。

简化 3

光钟是思维实验

光钟用来建立直觉，并非真实探测器；真实实验用原子钟、粒子寿命与 GPS 验证。画布还用"循环演示"让运动钟位置回卷，纯属可视化约定。

简化 4

只演示一个方向

画布展示时间膨胀与长度收缩的单向画面；"同时性的相对性"（两个事件是否同时取决于观察者）没有展开，它是解释许多佯谬的另一把钥匙。
