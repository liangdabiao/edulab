# 集合逻辑 — 可视化约定

## 文氏图

### 布局规则
- 1 个集合：圆形居中
- 2 个集合：两个圆心水平间距为半径的 1.2 倍，左右排列
- 3 个集合：三个圆心呈倒三角形排列（一个在上，两个在下）

### 着色
- 每个集合圆圈使用不同颜色的 8% 透明度填充，产生叠加效果
- `highlight` 字段可指定额外的交集着色
- 元素标签使用绝对定位的 `span`，均匀分布在圆心周围

### 元素标注
- 元素均匀分布在以圆心为中心的圆形区域内（半径 0.4× 圆半径）
- 元素文本使用 `venn-element` class（font-size:13px, font-weight:600）

## 真值表

### 布局规则
- HTML table，`truth-table` class
- 输入列在前（无背景色），输出列在后（蓝色高亮背景 `.highlight`）
- 行数 = 2^(输入变量数)
- 每一行：输入变量的所有组合（高位到低位）

### 列头
- 输入列显示变量名（`label`）
- 输出列显示表达式（`label`），`highlight` class 加蓝底

### 值表示
- 真值用 `1` 和 `0` 表示（非 True/False）
- 输出列使用 `highlight` class 高亮

## 逻辑门

### 门符号绘制规则

| 门 | 绘制方式 |
|----|----------|
| AND | 左直边 + 右半圆弧（quadraticCurve），形成 D 形 |
| OR | 左右两条贝塞尔曲线，汇合于右侧尖端 |
| NOT | 三角形（左宽右尖）+ 右侧小圆圈 |
| NAND | AND 形状 + 右侧小圆圈 |
| NOR | OR 形状 + 右侧小圆圈 |
| XOR | OR 形状 + 左侧额外曲线 |

### 门大小
- `size` 参数控制门高度的一半
- 门的宽度约为 size 的 1.5 倍
- NOT/NAND/NOR 的小圆圈半径固定为 5px

### 标注
- 标签文字绘制在门下方（y + size + 20）
