请基于 `skills/edu-sci-viz/templates/board-sci.html`，把下面这个科学主题做成一页**单文件互动科普 HTML**。

项目主题：
<主题对象，例如：日食 / 潮汐 / 卫星轨道 / 光的折射 / 四季 / 月相>

## 工作方式

1. 先**事实核验**：用网络检索权威来源（官方页面、教学资料、百科），确定关键数字、公式与结论。禁止虚构。
2. 复制 `board-sci.html` 到当前工作目录，替换以下四处，**保留模板的设计系统 `<style>`、通用运行时 `<script>`、importmap**：
   - `<title>` 与 hero 文案
   - 分节叙事 HTML（直觉模型 → 正式定义 → 边界说明 → 来源）
   - hero 实验台 `lab-shell`（画布 + 滑杆 + readout）
   - 底部「场景模块」`<script>`
3. 输出**单个 .html**，写到当前工作目录；不要留任何其它文件。

## 一、事实与资料要求

1. 先核验资料再写页面；所有重要结论能回到来源
2. 区分相邻易混概念；写清"已确认 / 已解决 / 仍开放"
3. 涉及数字、公式、引文必须真实；禁止虚构
4. 页面必须明确提示：演示只用于建立直觉，不能充当精确计算或证明

## 二、页面叙事结构（按序）

1. **hero**：`figure-no`（FIG. N / 主题名 LAB）、大标题（问句式，突出矛盾）、`hero-lead` 一句话点出核心规律、`开始实验` CTA、`hero-note` 操作提示；右侧 `lab-shell` 放互动实验
2. **直觉模型**（section-index 01）：把概念转成可操作画面，讲清"这道题到底在问什么"
3. **正式定义**（可选，section-index 02）：给出准确定义与关键术语区分，可用 `formula-box`
4. **这个模型简化了什么**：`limits-grid` 三列，逐条说明简化/省略/示意
5. **来源与核验路径**：`source-table` 列出全部来源，`source-policy` 说明数值近似口径

## 三、互动实验要求

1. 每个核心变量一个滑杆或开关，改变后立即更新模型与实时数值（readout）
2. 三维场景用 Three.js（importmap 已配好，场景模块里 `import * as THREE from "three"`，OrbitControls 用 `import { OrbitControls } from "three/addons/controls/OrbitControls.js"`），支持拖动旋转、滚轮缩放、重置视角、暂停
3. 二维场景用 HTML Canvas，给出可读的量化反馈
4. 性能：几何体初始化时创建，每帧只改变换；避免每帧重建大量对象
5. 检查 `window.__sciPaused` 停止自动运动；遵守 `prefers-reduced-motion`

## 四、视觉要求

1. 采用编辑部科学手册风（模板已内置，**禁止另造风格**）
2. 主背景暖米白、实验区深海军蓝、强调红 + 少量琥珀
3. 中文大标题宋体气质、参数/编号/图注等宽字体
4. 大量细线、编号、坐标网格和留白；保持科学、克制、现代
5. 禁止大面积渐变、玻璃卡片、荧光科技风和过度圆角
6. 首屏标题与实验面板保留安全间距，问号/标点不能被面板遮挡；`h1` 是 nowrap，标题每行 ≤6 汉字（模板已封顶 68px），行更长时在场景 `<style>` 覆盖 `white-space: normal` 折行，防止标题溢出压到右侧实验区

## 五、响应式与可用性

1. 至少检查 390×844、1440×900、1920×1080，无横向滚动
2. 手机端标题、画布和控制区重新排布
3. 所有按钮键盘可达；Canvas 有可读 aria-label；文字对比度充足
4. 遵守 prefers-reduced-motion

## 六、完成前检查

1. 实际打开页面检查首屏
2. 调节全部滑杆，测试拖动、缩放、重置、暂停
3. 检查所有来源链接、浏览器控制台无报错
4. 检查桌面与手机两档截图；确认标题末尾的问号完整可见
5. 1920 档用 `browser_evaluate` 比较 `h1` 文本右缘（nowrap 溢出时约等于 `left + scrollWidth`）与 `.lab-shell` 左缘，标题必须留有余量、不得压到实验区
