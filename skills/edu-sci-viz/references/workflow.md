# edu-sci-viz 工作流详解

把复杂数学/科学问题做成单文件互动科普页的通用方法论。前六步源自可视化科普的实践总结，第七、八步把成果组装成可直接在浏览器打开的单个 HTML。

## 第 1 步：事实核验（权威来源）

先查清事实，再想怎么呈现。

- 只信官方页面、原始论文和可靠综述（例如：NASA 官方页、HyperPhysics、Wikipedia 相关条目、机构新闻）
- 区分容易混淆的相邻概念（日食案例中要区分：本影 / 半影 / 伪本影；日全食 / 日环食 / 日偏食——三者常被新闻压缩成一句话）
- 写清"已解决 / 已确认 / 仍开放"的准确范围；涉及数字、公式、引文一律以来源为准
- 禁止虚构定理、数字、引文、论文结论和证明步骤

## 第 2 步：直觉模型

把抽象句子变成可以动手观察的现象。

- 找出主题的关键对象、变量、关系（光→入射角与折射率；月球→轨道位置与月地距离；海水→引潮力方向）
- 优先选择空间关系、时间变化、尺度变化、参数影响这四类可互动的维度
- 目标读者是第一次接触该概念的普通人：先让他们看懂"这道题到底在问什么"

## 第 3 步：正式定义

直觉建立后再给严格表述。

- 给出准确定义，解释关键术语差异（例如 Snell 定律 vs 全反射临界角；本影 vs 半影）
- 用可视化辅助定义理解（实时画布 + 滑杆 + 实时数值核验）
- 文字保持克制，不声称网页展示了完整推导或证明

## 第 4 步：互动实验设计（滑杆 + 实时反馈）

- 每个核心变量对应一个滑杆或开关，参数改变后立即更新模型与状态文字（readout）
- 三维：Three.js（模板已配 CDN importmap），支持拖动旋转、滚轮缩放、重置视角、暂停
- 二维：HTML Canvas，用像素统计 / 实时数值给出可读的量化反馈
- 性能：几何体在初始化时创建，每帧只更新变换；页面离开视口或开启减少动画时降低运动
- 可用性：按钮可键盘访问、Canvas 有 aria-label、文字对比度充足、无横向滚动

## 第 5 步：边界说明

诚实是科普的底线。

- 页面必须明确提示：演示只用于建立直觉，不能充当精确计算或证明
- 单列"这个模型简化了什么"区块：哪些简化、哪些省略、哪些数值是示意
- 若画面比例做过夸张（如天文场景），必须在边界区块注明

## 第 6 步：来源追溯

- 页面末尾列出全部来源链接：官方页面、教学资料、百科、数据库
- 所有重要结论都要能一一对应到某条来源
- 给出数值采用的近似口径（例如"预设值取 589 nm 钠黄光下的常用近似"）

## 第 7 步：单文件组装

从 `templates/board-sci.html` 复制一份到工作目录，然后替换四处：

1. `<title>` 与 hero 文案（大标题、lead、CTA、说明）
2. 分节叙事 HTML（直觉模型 → 正式定义 → 边界说明 → 来源），保留 `.section-heading` 结构
3. hero 里的实验台 `lab-shell`（画布 + 控制区：滑杆、预设按钮、实时 readout）
4. 底部「场景模块」`<script>`：把"光的折射"示例替换成你的主题

保留：`<head>` 里的设计系统 `<style>`、通用运行时 `<script>`（阅读进度 + 暂停 + 渲染循环）、importmap。3D 场景在场景模块里 `import * as THREE from "three"`；2D 场景无需引入。

组装后本地实测：

1. 起静态服务（`python3 -m http.server 8099`）打开页面，检查首屏与各区块
2. 调节全部滑杆，测试拖动、缩放、重置、暂停
3. 检查所有来源链接可点
4. 检查浏览器控制台无报错
5. 至少检查 390×844、1440×900、1920×1080 三档分辨率，无横向滚动
6. 标题、标点不被面板遮挡——**尤其要查 hero 标题是否溢出左列压到右侧实验区**：`browser_evaluate` 里比较 `h1` 的 `getBoundingClientRect().right`（文本实际右缘，nowrap 溢出时等于 `left + scrollWidth`）与 `.lab-shell` 的左缘，1920/1600 两档必须有余量

### 排版陷阱：hero 标题 nowrap 溢出

模板 `h1` 用 `white-space: nowrap` + 显式 `<br>` 控制标题形状。当标题某一行宽过左文字列（约 450px）时，nowrap 会让文本**溢出元素盒子、直接画在右侧深色实验区上**——视觉上像标题"压住/覆盖"了实验图。宽屏（1440/1920）字号拉满时最容易触发（如 `h1` 88px 时一行 6 个汉字即溢出）。

- 模板默认已把字号上限设为 68px ≈ 一行最多 6 个汉字；写标题时让每行 ≤6 汉字
- 某行必须更长时，不要依赖 nowrap 硬撑，在场景专属 `<style>` 里覆盖：
  `.your-scene .hero h1 { white-space: normal; }`，让该行在列宽内自然折行
- 自检时在 1920 用 `h1.scrollWidth > h1.clientWidth` 判断是否溢出，或直接比较文本右缘与实验区左缘

## 第 8 步：交付

- 交付给用户的**只有一个 .html**，写到当前工作目录（`Path.cwd()`）
- 临时构建脚本、截图放 `/tmp` 或用完即删，cwd 里不要留别的文件
- 预览结束立即停掉本地服务

## 场景模块接口约定

场景模块是一个普通 `<script>`（2D）或 `<script type="module">`（3D，需 import three），约定：

- 脚本顶层做初始化：找画布、绑滑杆、建 Three.js 场景、算初始状态
- 在 `window.SciScene` 上暴露 `update(dt)`，由模板通用运行时每帧调用
- 帧间隔 `dt`（秒）已由运行时封顶（≤0.05s）；检查 `window.__sciPaused` 以决定是否推进自动运动（3D 场景即使暂停也需继续 render 以保证拖动响应）
- 清理：`ResizeObserver`、`OrbitControls`、renderer 等视需要 dispose

## 主题选择建议

适合的主题：日食、月食、太阳系、四季、月相、潮汐、卫星轨道、板块运动、光的折射、彩虹、时区、极昼极夜……凡是有空间关系、时间变化、尺度变化或参数影响的问题。反之，纯文字可讲清、无参数可调的静态概念不适合本技能。

## 领域经验

化学主题（公式下标渲染、配平/守恒数据模型、反应动画状态机、静态画布"两卡片+提示行"布局）的经验单独成文：[chemistry.md](chemistry.md)。做化学科普页前先读。
