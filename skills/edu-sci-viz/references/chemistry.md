# edu-sci-viz 化学主题经验

本技能已产出并浏览器验证两个化学主题（2026-08-01）：

- `thermite-reaction.html` — 铝热反应（放热反应类，状态机动画）
- `redox-balance.html` — 氧化还原方程式配平 · 化合价升降法（配平/守恒核验类）

下面是从这两个主题沉淀的可复用经验。做任何化学科普页前先读这份。

## 化学公式渲染规范（下标一致性）

公式出现处必须带下标，且全页风格统一——这是用户最容易投诉的点（"公式样式有问题"）。

- **DOM 侧**（侧栏 stepper、卡片内文本）用 `toSub()` 把数字转 Unicode 下标，与数据里手写的 "Fe₂O₃" 一致：

  ```js
  const SUBCH = "₀₁₂₃₄₅₆₇₈₉";
  function toSub(f) { return String(f).replace(/[0-9]/g, (d) => SUBCH[+d]); }
  ```

- **Canvas 侧**：`drawSpecies(x, y, sp, size, color)` 逐字符画，数字用更小字号、基线下沉画成下标（下标 ≈ 0.62×正文，基线 `y + size * 0.28`）；字母与下标**统一同一字族**。不要字母 SANS + 下标 MONO 混排（显乱）。
- **系数与公式分离**：系数不拼进公式串，单独画在公式左侧（留 `coefW` 槽位）；公式字符串里所有数字一律按下标处理，天然免解析。

## 配平 / 守恒核验数据模型

写"化合价升降 / 原子守恒"类核验交互时的判据：

- **总升/总降不能按元素聚合，也不能按整物种系数乘**。反例：H₂S+SO₂ 里 S 在 H₂S 是 -2、SO₂ 是 +4，按元素聚合会正负抵消成 0；Cu+HNO₃ 里 HNO₃ 16 个只有 2 个被还原（其余作酸，是旁观物种）。正确做法：每个 change 显式声明**计数物种 `sp` + 每式原子数 `n`**（选"该元素身份唯一"的一侧：产物侧或反应物侧），贡献 = `coef[sp] × n × |Δ|`。
- **原子守恒独立核对**：用 element counts 抓作酸/作碱的旁观物种，与升降核算分开。
- **核验呈现**：canvas 底部"核验带"画每元素 L/R 绿红 chips + 总升/总降双条。`browser_evaluate` 断言：填正确系数 → 配平成功，任一系数 +1 → 未平衡。

## 反应动画（放热反应类，thermite 蓝本）

状态机写法：引燃 → 反应前峰 → 铁水沉底 / 炉渣浮顶 → 冷却；叠加温度-时间曲线；提供限量试剂 / 氧化物切换。动画每个时刻是一个原子状态，`update(dt)` 只推进状态机并重绘。

## 画布布局：两卡片 + 提示行

静态 / 步骤式画布内容少时（方程式 + 稀疏核验带），整张画布会显"空、broken"（用户投诉"整个可视化有问题"）。改法：

- **上下两张卡片**：方程式卡 + 演示/核验卡。`layoutCards(W, H)` 统一算卡几何（`cardX/cardW/eqTop/eqH/bandTop/bandH`），卡片内边距吸收空白，比硬凑元素好看。
- 每步底部一条 mono 小字口诀/提示（`bandHint`），如"升失氧、降得还——电子过手，升降必相抵"，既填空间又带教学价值。
- 移动端画布高度给足（本页 460→560px）；最宽元素（长方程式含系数，如 KMnO₄+HCl 六物种）实测要落在卡片内。
